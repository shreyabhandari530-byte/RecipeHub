# 🍽️ RecipeHub – Community Recipe Sharing Platform

## 📌 About the Project

RecipeHub is a Community Recipe Sharing Platform developed as part of the CodeNova Full Stack Development Internship.

It allows users to explore recipes, add their own recipes, view ingredients and cooking instructions, and share their favourite food ideas.

## ✨ Features

- Add new recipes.
- Explore different recipes.
- Search recipes by title, ingredient, or cuisine.
- Filter recipes by categories.
- View detailed recipe information.
- Display preparation time and difficulty level.
- View ingredients and cooking instructions.
- Like and favourite recipes.
- Store recipe information in a database.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST API

### Database
- SQLite

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shreyabhandari530-byte/RecipeHub.git
```

### 2. Navigate to the Project Folder

```bash
cd RecipeHub
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Start the Backend Server

```bash
npm start
```

### 5. Install Frontend Dependencies

Open another terminal:

```bash
cd frontend
npm install
```

### 6. Start the Frontend

```bash
npm run dev
```

Open the local URL displayed in the terminal to access RecipeHub.
