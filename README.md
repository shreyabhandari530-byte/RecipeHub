\# RecipeHub – Community Recipe Sharing Platform



\## About the Project

RecipeHub is a community recipe-sharing platform where users can explore, create, and share delicious recipes.



\## Features

\- Add new recipes with ingredients and cooking instructions.

\- Explore available recipes.

\- Search recipes by name.

\- Filter recipes by category.

\- View detailed recipe information.

\- Like and favourite recipes.

\- Responsive and user-friendly interface.

\- Store recipe information in a database.



\## Technologies Used



\*\*Frontend\*\*

\- React.js

\- JavaScript

\- HTML

\- CSS



\*\*Backend\*\*

\- Node.js

\- Express.js

\- REST API



\*\*Database\*\*

\- SQLite



\## Project Structure

\- frontend – User interface

\- backend – Server and API

\- screenshot – Project screenshots



\## Installation and Setup



\### 1. Clone the repository

```bash

git clone https://github.com/shreyabhandari530-byte/RecipeHub.git

```



\### 2. Install backend dependencies

```bash

cd RecipeHub/backend

npm install

```



\### 3. Start the backend

```bash

npm start

```



\### 4. Install frontend dependencies



Open another terminal:

```bash

cd RecipeHub/frontend

npm install

```



\### 5. Start the frontend

```bash

npm run dev

```



Open the local URL displayed in your terminal.
